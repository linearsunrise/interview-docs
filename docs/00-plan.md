# План подготовки

## Стратегия для senior-собеседования

На senior-уровне проверяют три вещи, и готовиться нужно ко всем трём:

1. **Глубина** — не «что такое event loop», а «почему setImmediate внутри I/O-колбэка сработает раньше setTimeout»
2. **Trade-offs** — каждый ответ должен содержать «зависит от», с объяснением от чего именно
3. **Опыт** — истории из практики: «у нас была утечка памяти, нашли через heap snapshot, причина была в...»

## График (пример на 4 недели)

| Неделя | Темы | Фокус |
|--------|------|-------|
| 1 | JS/TS, Node.js Core | Глубина: event loop, streams, память |
| 2 | NestJS, Базы данных | DI, request lifecycle, индексы, транзакции |
| 3 | Архитектура, API, Безопасность | Паттерны, микросервисы, trade-offs |
| 4 | System Design, Perf, Infra + mock-интервью | Проектирование вслух, повторение |

## Ежедневная рутина

- 1–2 часа теории по текущему блоку
- 30 мин — проговаривание ответов **вслух** (критично: знать ≠ уметь рассказать)
- Записывай в каждый док свои формулировки ответов — они запоминаются лучше чужих

## За 2–3 дня до собеседования

- Пройди `12-mock-interview.md` — вопросы для самопроверки
- Подготовь 3–4 истории по STAR: сложный баг, архитектурное решение, конфликт/менторинг, фейл и выводы
- Повтори «Красные флаги» во всех доках — проверь, что не делаешь этих ошибок
