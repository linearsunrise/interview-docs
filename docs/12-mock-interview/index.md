## System design: финальный прогон

Выбери 2 задачи, которые не разбирал, и пройди по таймеру 40 минут вслух:
- [ ] Требования и цифры озвучены до архитектуры
- [ ] Названы trade-offs минимум в 3 решениях
- [ ] Разобран failure mode хотя бы одного компонента

## Поведенческое

- [ ] 4+ STAR-историй рассказываются свободно за 2–3 минуты
- [ ] Готов ответ «почему уходите» без негатива
- [ ] Есть 5 вопросов интервьюеру

## День интервью

- Не учить новое — только беглый повтор тезисов и красных флагов
- На вопросах: думать вслух, уточнять требования, честное «не сталкивался, но рассуждал бы так» лучше выдумки
